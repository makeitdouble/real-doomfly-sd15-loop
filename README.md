# REAL DOOMFLY -> QWERTY -> SD1.5 LOOP v10

Что поменял в v10:

- оставил реальный DOOMFLY + QWERTY + ComfyUI цикл
- сохранил увеличенные зоны **SPACE / ENTER / DELETE**
- добавил **детектор английских слов**
- добавил **partial reward** за почти-слова и за осмысленный префикс последнего слова
- добавил **награду за итоговый prompt**: чем больше правильно написанных английских слов, тем выше reward
- если в одном prompt несколько нормальных слов — reward выше
- добавил лёгкий **reinforcement overlay** поверх моторных действий:
  - базовое действие всё ещё приходит из DOOMFLY
  - но теперь рядом живёт маленькая policy-память
  - удачные действия, которые вели к более «английскому» тексту, получают усиление
- в UI добавлен блок **LANGUAGE REWARD**:
  - buffer score
  - cumulative reward
  - exact words
  - near words
  - prefix bonus
  - base action -> final action

## Что это значит по сути

Теперь муха не просто случайно тыкает клавиши.
Она получает дополнительный сигнал:

- написал больше настоящих английских слов -> лучше
- написал два слова вместо одного -> лучше
- написал почти-слово (`futer` рядом с `future`) -> немного лучше
- дополз до хорошего префикса (`ca` -> возможно `cat`) -> маленький бонус

Это не «настоящая тренировка connectome с перепрошивкой весов», а **лёгкая внешняя наградная надстройка**. Но для твоего эксперимента это уже намного ближе к идее:

> муха печатает -> видит результат -> получает reward -> постепенно тяготеет к более осмысленным строкам.

## Запуск

1. Распакуй архив.
2. Убедись, что ComfyUI работает на `http://127.0.0.1:8188`.
3. Убедись, что real DOOMFLY graph уже подготовлен.
4. Запусти `run_real_brain.bat`.
5. Открой `http://127.0.0.1:8951`.

Если хочешь просто проверить интерфейс без ComfyUI — запускай `run_mock.bat`.

## Важно

- reward-память пока **не сохраняется на диск**; после перезапуска обучение начинается заново
- словарь встроенный, практичный, ориентирован на обычные английские слова и prompt-слова
- это именно экспериментальная v10, чтобы посмотреть: станет ли поведение смешнее и осмысленнее визуально


## Что добавлено в этом апдейте

- маленький **one-shot reward прямо во время набора**, когда впервые собралось совпавшее слово
- отдельный tiny reward за почти-слово тоже во время набора
- после **ENTER** теперь кидается отдельный **сильный общий reward**
- чем больше слов в итоговом prompt, тем сильнее submit reward
- повторный reward за одно и то же слово не спамится каждый тик: он даётся единоразово, пока слово реально собрано
